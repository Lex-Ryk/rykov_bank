# Rykov_Bank
Цель проекта: [научиться пользоваться инструментами для backend‑разработки (работа с Poetry, Git, написание и запуск тестов, обработка данных и т.д.)].

## Установка
Для запуска проекта необходимо установить зависимости и активировать виртуальное окружение:

Убедитесь, что у вас установлены Python (версии 3.9 или выше) и Poetry.
Активируйте виртуальное окружение проекта:
```
poetry env activate
```
Установите зависимости проекта:
```
poetry install
```
При необходимости установите зависимости для разработки (включая pytest):
```
poetry add --group dev pytest
```
## Тестирование
Проект использует pytest для автоматизации тестов. Тесты расположены в директории tests/.

### Запуск тестов
Чтобы запустить все тесты:
```
poetry run pytest
```
Чтобы запустить тесты с подробным выводом (verbose):
```
poetry run pytest -v
```
Чтобы запустить только тесты для конкретного файла:
```
poetry run pytest tests/test_get_date.py
```
Чтобы запустить тесты с отчётом о покрытии ими тестируемых функций:
```
pytest --cov
```
А если вам необходимо сохранить этот отчёт в файл html, то:
```
pytest --cov=src --cov-report=html 
```
